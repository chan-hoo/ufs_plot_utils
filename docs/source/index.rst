ufs_plot_utils documentation
============================

A modular, YAML-driven visualization pipeline for UFS, UFS-DA, FV3, MOM6,
CICE, restart, forecast, increment, and observation datasets.

Features
--------

- YAML-driven plotting workflow
- Support for FV3 tiled cubed-sphere grids
- Support for MOM6 and CICE structured grids
- Observation plotting (IODA format)
- Difference plotting between datasets
- Forecast and restart automation
- Configurable Cartopy projections and styling
- Task-based modular architecture
- Extensible plotting and I/O framework
